# Инвариант

Проба города даёт **три** исхода: `SELLABLE`, `NOT_SELLABLE`, `MISRESOLVED`.
При расхождении региона пробер **ретраит** варианты имени по порядку
(алиас из `data/city_aliases.json` → имя как есть → «имя, субъект»), и только
исчерпав их — фиксирует `MISRESOLVED`. Продаваемость читается по
`meta.modes_summary` и `meta.unavailable`, не по числу вариантов. Непродаваемый
узел **не удаляется** (режим «дальше своим ходом»).

# Почему нерушимо

Цепочка B1 детерминирована: «Ростов» в `cities_ru.json` → резолвится в
Ростов-на-Дону → guard срабатывает → если исход схлопнут в `NOT_SELLABLE`,
Ростов Великий тихо исчезает из реестра → эталонный маршрут перестаёт
существовать, и причина выглядит как «Ростов Великий не продаётся» — ровно та
ложь, от которой guard защищает.

# Что считать нарушением

- Пробер знает только два исхода.
- Отказ с первой попытки без ретрая по вариантам имени.
- Регресс-тест ингеста не проверяет присутствие эталонных узлов (Ярославль,
  Ростов Великий, Рязань, Коломна, Тула, Калуга, Владимир, Иваново).

# Как проверяю

Enum исхода в схеме (`hub.probe_status`), наличие `data/city_aliases.json`,
падающий регресс-тест при отсутствии эталонного узла.
Связано с [guard-before-price](guard-before-price.md).
