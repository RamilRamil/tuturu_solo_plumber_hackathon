# Инвариант

- **Фаза 1** локальна и синхронна (`< 200 мс`), **ни одного** сетевого вызова
  наружу. Только предпосчитанные данные.
- **Фаза 2** — живые вызовы Tutu, строго по SSE, и **только для топ-5** кластеров
  после отбора.

# Почему нерушимо

Латентность Tutu 0,7–26,7 с (медиана ≈3 с). Синхронный UX невозможен.
Ранжировать кластеры по «продаваемости перегона» нельзя — это стоило бы вызова
за каждого кандидата (логический круг, `risks.md` §2). Поэтому отбор топ-5 идёт
по локальным данным, и только потом — сеть.

# Что считать нарушением

- Любой сетевой вызов в пути `/api/places` (фаза 1).
- Живой вызов Tutu до отбора топ-5 (например, чтобы «уточнить ранжирование»).
- Синхронное ожидание всех цен вместо стрима (первый `leg` обязан прийти ~3 с,
  не после всех — `open-issues.md` V3).
- Окна дат, посчитанные жадно (140 вызовов) вместо лениво.

# Следствие для UI

После ввода origin часть найденных мест окажется недостижимой. Такие карточки
**не исчезают — сереют с причиной**. Это прямое следствие границы: в фазе 1 цен
и достижимости ещё нет. См. [sellability-is-edge](sellability-is-edge.md).
