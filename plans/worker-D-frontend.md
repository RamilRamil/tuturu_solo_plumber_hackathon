# План: Рабочий D — Фронт (React + MapLibre)

Ты собираешь интерфейс. Стартуешь **сразу** на замоканном контракте API — не ждёшь
бэкенд. Как только контракт заморожен Архитектором, моки = реальные ответы.

Читать: `mvp-spec.md` §3/§4/§10, `open-issues.md` V2/V4, `ingredients.yaml`.
Зависишь от: контракт API (`plans/api-contract.md`, Архитектор час 1–2).
Стек: React + MapLibre (**не Leaflet** — тысячи точек, Leaflet рисует каждую как DOM).

## Бургер-меню (час 3–16)

~20 карточек ингредиентов + поле «другое» с подсказками. **Метка плотности на
каждой карточке обязательна** (V4/§8): храмы 370, водопады 0 — иначе пользователь
соберёт несуществующую комбинацию. Плотность приходит из `/api` (готовит B).

## Ползунок радиуса (V2)

**Дискретные шаги 50/100/150 с защёлкой**, не свободный. Счётчик найденных мест
на каждый шаг (предпосчёт на бэке). Верхняя граница — 150 км (порог D2), выше не
пускать. Дефолт 100.

## Карта + карточки (фаза 1, час 10–26)

MapLibre: все объекты кластера на карте, топ — в карточке. Карта + карточки рядом,
топ-5. Карточка: hubs, диаметр, coverage (matched/missing), редкость, объекты.
В фазе 1 **цен нет** — не показывать бюджет.

## Потребление SSE (фаза 2, час 16–26)

После ввода origin/дат/состава — `/api/price` по SSE. Рендерить события по мере
прихода (`leg`, `hotel`, `breakdown`, `checkout`, `warning`, `done`). Результаты
появляются постепенно, не ждать все. **Раскладка по категориям обязательна**
(транспорт/жильё/итого). Кнопка оформления = `checkout_url` как есть, не трогать URL.

Поля состава: «взрослые» и «дети» (возрасты). Бюджет по умолчанию только транспорт,
переключатель «всё».

## Серые карточки и «почти подходит» (час 26–34)

- **Недостижимые после origin не исчезают — сереют с причиной** (§3). Непродаваемые
  узлы — пометка «дальше своим ходом».
- Блок «почти подходит» — неполные совпадения (покрыт не весь бургер) отдельно.
  *(При пожаре по таймлайну этот блок режется первым — см. B4.)*

## Карта покрытия данных (V4, час 26–34)

Жюри смотрит само. «Данные загружены по N областям», регионы без данных —
штриховкой. Честная дыра читается как этап, скрытая — как поломка. Список залитых
регионов приходит от A (D3).

## Часы работы объектов

Три состояния (открыт/закрыт/неизвестно) — 88% без тега. Веб-поиск часов —
**лениво, только после клика** по объекту, не заранее.
