## Черновики оркестратора (первый прогон, не заморожены)

Записать в артефакты (schema / api-contract / orchestration §3 / §6) либо
отклонить одной фразой. Молча не игнорировать.

**G2 `cluster_id`:** `"c:" + ",".join(sorted(hub_id))`. Идентичность = множество
узлов. Радиус и фаза не входят. `title` не ключ. Неизвестный id → 404.

**G3:** узел в `cities_ru.json` → `expected_region = subject` (канон против OSM).
Узла нет → `name:ru` (иначе `name`) полигона OSM `admin_level=4` (point-in-polygon).
Нет полигона → `misresolved`, узел не удалять. Фикстура G3 ≠ Ростов Великий.
Расхождение OSM vs subject при наличии записи в справочнике: OSM только в лог.

**G5 ветка <4:** 4+ как план; 2 → D2 сразу порог 100 km + только sellable с POI;
1 → D2 только эталон + запасной + регресс B1 п.4, волны 2–3 D1 режутся; D5 только
два сценария приёмки.

**G6 nginx:** `proxy_buffering off; proxy_cache off;` ответ
`Cache-Control: no-cache`, `X-Accel-Buffering: no`,
`Content-Type: text/event-stream`.

**G8:** один FastAPI (роутеры B+C), порт 8000; фронт React 18 + Vite + TypeScript +
MapLibre (не Leaflet), npm, Node 20; бэк Python 3.12 FastAPI SQLite; compose:
backend, frontend, nginx:80 как прод; git: `main` + `stream-a|b|c|d-*`, швы
мержит архитектор; `.db`: `data/burger.db` на VPS, rsync/scp (или общий volume),
в git только золотой срез `fixtures/`.

(1) эталон №1 в топ-5 `/places` — SC-ranking; (2) запасной бургер в топ-5 —
