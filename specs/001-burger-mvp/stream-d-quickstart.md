## Сценарий A — эталон без origin (UI не сортирует)

1. Открыть UI. Поля origin / дат / бюджета **нет или неактивны** (инверсия).
2. Включить `ancient_temple` и `industrial_museum`. Ползунок защёлкнуть на **100**.
3. Запрос фазы 1 (мок `POST /api/places`: `ingredients` эти два, `radius_km: 100`).
4. **Ожидание:** список в порядке ответа; UI не переставляет карточки. Карточка «Ярославль и Ростов Великий» / тот же `cluster_id` **есть** (позиция любая). Цен, `breakdown`, кнопки оформления нет.
5. На карте — объекты выбранного кластера; в карточке пары — хабы, `diameter_km`, `coverage` без дыр эталона, редкость как пришла с бэка (не вау).

Провал: клиент сортирует `places[]`; цена на карточке; запрос с origin; комбо заводов.
Одиночный Ярославль выше пары; пара ниже пятого на моке — **не** провал UI.

## Сценарий B — SSE по одному на том же `cluster_id` (G10)

1. Остаться на карточке **пары** эталона из A (кликнуть её, даже если выше в списке одиночный Ярославль). Не искать заново другой кластер.
2. Ввести origin **Москва**, дни **3**, месяц **2026-10**, взрослые **1**. Бюджет по умолчанию `transport`.
3. Старт `POST /api/price` с **тем же** `cluster_id`.
4. **Ожидание (глазами, не в DevTools-пачке):**
   - сначала `resolved`;
   - затем хотя бы один `leg` (не ждать все плечи);
   - далее `hotel` / `warning` по мере мока;
   - `breakdown` (транспорт / жильё / итого) до или вместе с `done`;
   - `price_status: fixture-confirmed`;
   - между событиями заметная пауза (не три JSON сразу).
5. Оформление: URL кнопки = `checkout_url` события, без правок.
6. Итог 4342 из фикстуры **не** подписывать как живой SC-price.

Провал: другой `cluster_id`; спиннер до `done`; пачка SSE; переписанный checkout; снятие `fixture-confirmed`.

## Ползунок и плотность (дымовые)

- Шаги только 50 / 100 / 150; >150 нет.
- На 50 и 150 мок отдаёт `total_found` (может отличаться); `cluster_id` эталона при тех же хабах тот же.
- Водопад `absent_in_region` / храм `dense` видны в меню до поиска.

## Шеринг (не G10, часы 40–44)

Когда дойдут: в query — percent-encode **всей** строки `cluster_id`, не сырой path.  
Пример смысла: `cluster_id=` + `encodeURIComponent("c:Ростов|Ярославская область,Ярославль|Ярославская область")`.
